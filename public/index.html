Доказательства, не мнения

На каждый из 15 элементов модель отвечает «спрошено / присутствует», объясняет почему и приводит цитату. Код находит цитату в расшифровке и ставит тайминг.

Выбор модели по цифрам

Четыре модели на одних эталонах против человека. Дешёвая на поток, дорогая на спорные. Весь бюджет 7 800 ₽ в месяц при согласованных 10 000.

Как устроено внутри
  • Речевые метрики из диаризации: доля речи менеджера (норма 45–60 %), длина монологов, темп, паузы, вопросов в минуту.
  • Формула балла: цель встречи 30 + элементы 30 + этапы 25 + речь 15; красная зона перекрывает всё. Вкладка каждого менеджера с его личным скриптом.
  • Обезличивание перед отправкой модели с обратной подстановкой в ответе. Содержание встреч не попадает в логи и git.
  • Раннер GitHub Actions, четыре сценария: пакет по листу, одна запись, диаризация, пересчёт. Смена провайдера моделей за день, когда прежний ограничил аккаунт.

Неотличим от менеджера

Персона и примеры из реального корпуса переписки, дебаунс, «печатает…», тайминги как у человека. Защита от инъекций и провокаций: два подряд и бот замолкает.

Критики на агентах

Живые диалоги разбирают шесть ролей (судья правил, уход клиента, голос, сверка с CRM, парсер) и скептик, который отбросил 4 из 14 находок как ложные.

Как устроено внутри
  • Cloudflare Pages Functions + D1, деплой из GitHub Actions, двусторонняя интеграция через API чатов amoCRM (amojo) с подписью запросов.
  • Диалог как конечный автомат: приветствие → касания → квалификация → передача. Ночная ветка, лесенка цены, четыре разных захода за номером.
  • Нецелевых (команда меньше 5 или оборот ниже порога) бот мягко отсеивает и закрывает сделку автоматически.
  • Статистика: воронка по диалогам, медианы ответа по менеджерам, источники с раскрытием до страницы и переписки.
  • Ловушка, которую поймал: автоназначение ответственного в CRM система считала перехватом человеком и глушила бота. Закрыто списком служебных пользователей и окном 60 секунд.
  • Дочитали досюда? Значит, вы из тех, кто изучает, а не листает. Для вас тут кое-что есть 🐾

Для руководителей

Воронки план/факт с прогнозом на месяц, конверсии между ступенями, срезы по источникам, тегам и UTM, звонки по менеджерам первой линии.

Для команды

Права по разделам и ролям, вход через Telegram, генератор ссылок для блогеров, карта воронок, дашборд проектов и утренний бриф в Telegram.

Как устроено внутри
  • Cloudflare Pages + Workers + D1 + KV. Сборщик ночью тянет CRM, звонки АТС, Яндекс Метрику и таблицы; страницы читают API.
  • Подготовка диагноста к встрече: по переходу сделки на этап «встреча подтверждена» модель собирает досье в четыре шага. После пилота стоимость 335 ₽ за подготовку снижена базой знаний «было → стало».
  • Разбор встречи после: лояльность клиента, ключ к следующему контакту, контекст для бота пингов.

27 дней без движения → задача ответственному, 30 дней → закрытие с причиной. Лимит на запуск, список исключений, тег «не автозакрывать», сухой прогон при ручном старте.

Сторож за один день

Вебхук ловит перенос сделки в чужую воронку, пишет в Telegram, откат по кнопке. Пять инцидентов за месяц закрыты в день обнаружения.
